This repository holds a passport that was never issued, for a country that is not on any map: the Republic of Vespera, a fog-bound alpine microstate whose capital is Port Vesper. The entry's program writes a single image — an open passport spread. On the left, the data page of Marta Ilse Vesk: her portrait, bilingual English–Vesperan fields, a signature, and a machine-readable zone whose check digits are honestly computed from the same data. On the right, a visas page stamped in travel order by the neighbouring states of Kestria and Ostmark — and the one detail that gives the place away, a violet FOG TAX — PAID stamp from Port Vesper. The spread was typeset as a document rather than painted: it is rendered from `spread.html` in a headless browser, so every stamp, date and field agrees with every other. Built for make.fun's "The Passport Page of a Country That Isn't There" bounty.
